# ImlaScript models

Speech models converted to the [whisper.cpp](https://github.com/ggerganov/whisper.cpp) (GGML) format for ImlaScript.
They also work in any whisper.cpp program. Each model is a release here. Its notes give the original model, its
author, its licence, the language code to run it with, how it was converted, and the measured quality.

**The models belong to their authors.** These releases only change the file format and keep each original
licence.
